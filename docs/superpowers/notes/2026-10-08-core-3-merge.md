## Birleştirme ve çıkış (sahibi; tek satır, bir kez)

```
cd ~/Projects/control-center && L=~/.control-center/office.lock && { [ ! -e "$L" ] || { P=$(cat "$L"); kill -INT "$P" 2>/dev/null; while kill -0 "$P" 2>/dev/null; do sleep 1; done; }; } && (set -C; git rev-parse HEAD > ~/.control-center/main.pre-core3) && node -e 'new (require("node:sqlite").DatabaseSync)(process.argv[1],{readOnly:true}).prepare("VACUUM INTO ?").run(process.argv[2])' ~/.control-center/office.db ~/.control-center/office.pre-core3.db && git merge --no-ff --no-edit integration/core-3 && pnpm office
```

Satır sırasıyla:
1. Ofis açıksa durdurur ve kapanmasını bekler. Bu, economy runbook'u §10b'deki komutun aynısıdır. Kilit dosyası
   yoksa ya da eskiyse geçer.
2. main'in şimdiki commit'ini `~/.control-center/main.pre-core3`'e yazar; geri alma bunu kullanır. Dosya **varsa
   durur** (`set -C`), hiçbir şeye dokunmadan: "cannot overwrite existing file". Satır daha önce çalışmış demektir.
3. Veritabanının tutarlı bir yedeğini alır: `office.pre-core3.db`. Dosya varsa durur ("output file already exists").
4. `integration/core-3`'ü `--no-ff` ile birleştirir. main `faf89ad`'deyken de, adım 1 alınmışken de temiz.
   main başka bir yerdeyse (prova dışı commit'ler) birleştirmeden önce bana ya da Kerem'e sor.
5. Ofisi başlatır; açılışta göç v16–v18 uygulanır. Sonra açık sekmeyi bir kez yenile.
